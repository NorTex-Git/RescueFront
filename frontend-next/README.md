# RESCUE Frontend

Frontend de RESCUE construido con Next.js, React y Tailwind CSS.

## Desarrollo

```bash
pnpm install
pnpm run dev
```

La aplicación queda disponible en `http://localhost:3000`.

## Validación

```bash
pnpm run lint
pnpm run test
pnpm run build
```

## Producción

Desde la raíz de `RescueFront`:

```bash
docker compose up -d --build
```
